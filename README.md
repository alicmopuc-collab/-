# Time Boutique — Telegram-бот мини-магазин часов

Минималистичный бот: каталог по брендам → карточка с фото → корзина → заказ.
Без эквайринга: после «Оформить заказ» админу приходит уведомление с контактами клиента и составом заказа.

## Запуск
1. Создайте бота у [@BotFather](https://t.me/BotFather), получите токен.
2. `cp .env.example .env` и заполните `BOT_TOKEN`, `ADMIN_IDS` (свой ID — командой `/id` в боте или через @userinfobot), `CONTACT`.
3. `pip install -r requirements.txt && python bot.py`
4. Откройте бота и нажмите /start (админ должен хотя бы раз написать боту, иначе Telegram не даст ему слать сообщения).

## Каталог
Всё в `catalog.json`: бренды → модели (`id`, `name`, `price`, `desc`, `photo`).
Текущие модели и цены — **примеры**, замените своими.
`photo` — путь к файлу (например `photos/rolex-dj41.jpg`) или ссылка `https://...`; пусто — карточка без фото.

## Админ
- Уведомление о новом заказе с кнопкой «✅ Связался»
- `/orders` — последние 10 заказов

## Поиск и фильтр по цене
В каталоге есть «🔍 Поиск» и «💰 По цене».
- Поиск ищет по бренду, модели и описанию: `rolex`, `submariner`.
- Цену можно вписать в поиск: `5000-10000`, `до 5000`, `от 10000`.
- Кнопки диапазонов считаются автоматически по ценам из `catalog.json`.

## Редактирование каталога из бота
Админ (ID из `ADMIN_IDS`) видит в меню кнопку «⚙️ Каталог (админ)» или может написать `/admin`.
- Добавить модель: бренд → название → цена → описание → фото (файлом, ссылкой или `-`, если без фото)
- Изменить модель: название, цену, описание, фото; удалить модель
- Новый бренд, удаление бренда вместе с моделями
- Изменения сразу пишутся в `catalog.json` и видны покупателям без перезапуска.
  Фото, загруженные через бота, хранятся как Telegram file_id (привязаны к этому боту).
- Если бот запущен из git-копии, бот меняет `catalog.json` на сервере, а не в репозитории.

## Рассылка клиентам
«📣 Рассылка клиентам» в админ-меню (`/admin`): пришлите текст или фото с подписью, посмотрите предпросмотр и подтвердите отправку.
- Получатели — все, кто хоть раз писал боту (после обновления бот начинает их запоминать).
- Клиент может отключить рассылку командой `/stop`; `/start` включает её снова.
- Заблокировавшие бота помечаются и больше не получают сообщения; в конце бот присылает итог: доставлено / заблокировали / ошибки.
- Не рассылайте слишком часто: клиенты, получающие много сообщений, жмут «заблокировать».
